# 🍽️ MyGastronomyYt

**MyGastronomyYt** é uma aplicação web do tipo **marketplace/restaurante** — parecida com o iFood — que permite visualizar cardápios, escolher itens, montar pedidos e finalizar pagamentos. O projeto possui **frontend** (interface do cliente) e **backend** (API REST) e foi desenvolvido para simular o fluxo completo de um site de restaurante/pedido online.

---

# 🧭 Visão Geral

A aplicação permite que usuários naveguem pelo cardápio, adicionem itens ao carrinho, façam pedidos (com criação, atualização e acompanhamento) e realizem pagamentos. O backend gerencia restaurantes, menus, itens, pedidos, usuários e integrações de pagamento; o frontend oferece a experiência de cliente (busca, carrinho, checkout, acompanhamento do pedido).

---

## ⚙️ Tecnologias Utilizadas

### Backend
- **Node.js** — ambiente de execução JavaScript
- **Express.js** — framework para criação de APIs
- **MongoDB / Mongoose** — banco de dados não relacional (ajuste se usar outro)
- **dotenv** — gerenciamento de variáveis de ambiente
- **cors** — liberação de acesso entre domínios
- **nodemon** — para desenvolvimento com atualização automática

### Frontend
- **React.js** — biblioteca principal para construção da interface
- **Vite** — ferramenta de build rápida para desenvolvimento moderno
- **Axios** — para integração com a API
- **React Router DOM** — controle de rotas no frontend
- **CSS Modules / Styled Components** — estilização dos componentes
- **Bootstrap / TailwindCSS** — (caso esteja sendo usado para layout)
