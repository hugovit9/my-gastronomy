# 🍽️ MyGastronomy

**MyGastronomy** é uma aplicação web completa desenvolvida para amantes da gastronomia, com o objetivo de compartilhar, visualizar e gerenciar receitas de forma simples e intuitiva.  
O projeto é dividido em **frontend** e **backend**, utilizando tecnologias modernas e uma arquitetura escalável.

---

## 🧭 Visão Geral

A aplicação permite que o usuário explore receitas, adicione novas, visualize detalhes e interaja com conteúdos culinários.  
O backend fornece uma API RESTful robusta, enquanto o frontend oferece uma interface interativa e responsiva.
